# شوارع الشام 3D / Sham Streets 3D

مشروع لعبة عالم مفتوح سورية أصلية للأندرويد باستخدام Godot 4.

## الحالة
بداية برمجية: مدينة هندسية مؤقتة، شخصية قابلة للتحريك، كاميرا خلفية، قفز، ومدخلات لمس أساسية. لم يتم التحقق من تشغيل المشروع في محرك Godot بعد. **ليست لعبة مكتملة أو APK منشوراً.**

## الخطة
1. تثبيت أساس المشروع والاختبارات
2. بناء أحياء حلب وشخصياتها
3. سيارات ودراجات وقيادة
4. مارة ومرور وشرطة
5. ملابس ومحلات ومهمات
6. إضافة دمشق
7. اقتصاد داخل اللعبة وحفظ
8. اشتراكات VIP والتحقق من دفع شام كاش
9. مراجعة سياسة المتجر ودمج إعلانات AdMob
10. تحسين أداء أندرويد واختبارات وإطلاق

## ملاحظات
- لا تضع أسراراً أو مفاتيح دفع في المستودع.
- المستودع كان عاماً عند أول رفع؛ تحويله إلى خاص يتطلب صلاحيات إدارة غير متاحة عبر الاتصال الحالي.
- الدفع بشام كاش داخل تطبيق موزع على Google Play يحتاج مراجعة سياسات الدفع المعمول بها قبل الإطلاق.
- التطوير يتم على نفس المستودع مع حفظ الإصدارات.

# شوارع الشام 3D / Sham Streets 3D

مشروع لعبة عالم مفتوح سورية أصلية للأندرويد باستخدام Godot 4. يحتوي هذا الإصدار التطويري على منطقة واحدة مستوحاة من سوق حلب، وسيارة قابلة للقيادة، ومهمة توصيل ومتجر ملابس وحفظ محلي، إضافة إلى مارة ومرور ودورية وخريطة مصغرة.

## التشغيل

افتح `project.godot` في Godot 4.6.3 وشغّل المشهد الرئيسي باستخدام F6 من `main.tscn` أو F5 من المشروع. استخدم الأسهم أو WASD للحركة والقيادة وShift للركض وSpace للقفز أو الفرملة. مفاتيح F للضرب وG للإطلاق وR للتلقيم وH لبوق السيارة. استخدم V للركوب أو النزول وE للتفاعل وF5 للحفظ أثناء اللعب خارج المحرر. حرّك الكاميرا مع الضغط على زر الفأرة الأيمن.

على اللمس، استخدم أسهم الشاشة أو اسحب النصف الأيسر للحركة أو القيادة، واسحب المساحة الفارغة في النصف الأيمن لتدوير الكاميرا. اقترب من السيارة واضغط «ركوب» للصعود، ثم أوقفها قبل النزول. اتبع العلامة الأرضية لتسلّم الطلب وتسليمه ثم زيارة متجر الملابس.

## الاختبار المحلي

نفّذ الأوامر من جذر المشروع باستخدام Bash ومجلد بيانات مؤقت منفصل عن حفظ اللاعب.

```bash
godot --headless --editor --import --path . --quit
XDG_DATA_HOME=$(mktemp -d) godot --headless --fixed-fps 60 --path . \
  --script res://tests/playable_smoke.gd -- --isolated-save
```

## بناء أندرويد

ثبّت قوالب تصدير Godot المطابقة لإصدار المحرك وOpenJDK 17 وAndroid SDK. اضبط مسارات Java وAndroid SDK في إعدادات المحرر وفق [وثائق التصدير الرسمية](https://docs.godotengine.org/en/stable/tutorials/export/exporting_for_android.html).

```bash
mkdir -p build
godot --headless --path . --export-debug "Android Debug" build/sham-streets-debug.apk
```

للـAAB، ثبّت قالب Android لمشروع Gradle من قائمة Project في Godot، واضبط توقيع الإصدار محلياً، ثم نفّذ الأمر التالي. اعتمد معرّف الحزمة مع مالك المشروع قبل أول نشر. ارفع رمز الإصدار لكل إصدار لاحق. احفظ بيانات التوقيع خارج المستودع.

```bash
godot --headless --path . --export-release "Android Release" build/sham-streets.aab
```

راجع [سجل التطوير والاختبارات](docs/PROGRESS.md).

## معاينة الويب للموبايل

يستخدم إعداد `Web Mobile` قالب الويب الرسمي دون خيوط وشاشة بدء عربية. بعد تثبيت القالب المطابق لـGodot 4.6.3، نفّذ من جذر المشروع:

```bash
mkdir -p build/web
touch build/web/.gdignore
godot --headless --path . --export-release "Web Mobile" build/web/index.html
gzip -n -9 -f build/web/index.wasm
python3 -m http.server 8765 --directory build/web
```

تُخدّم ملفات هذا المجلد عبر HTTPS عند النشر. قدّم `index.wasm.gz` كما هو، إذ تفك شاشة البدء ضغطه في المتصفح. يتطلب التشغيل WebGL 2.

## الكاميرا والخريطة

استخدم زرّي «تقريب» و«إبعاد»، أو حرّك إصبعين في جهة الكاميرا. على الكمبيوتر استخدم عجلة الفأرة أو + و-. تعرض الخريطة المصغّرة اتجاه اللاعب والطرق الجديدة والحديقة وعلامة المهمة.

تضم خريطة حلب في اللعبة حيدرية والصاخور ومساكن هنانو وميسلون. اضغط «الخريطة» أو مفتاح M، واختر حياً لإظهار مسار إرشادي على الشوارع الرئيسية.
